# SciQuest Backend

Backend of **SciQuest**, an academic scientific article search engine
developed at ESI Algiers.

## Stack

- Python
- Django
- Elasticsearch
- Relational database

## Project

The backend handles authentication, article management,
search and indexing, administrator/moderator features and
communication with the SciQuest frontend.

Projet académique réalisé en équipe à l'ESI Alger.
